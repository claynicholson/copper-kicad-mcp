Copper for KiCad: quick start

Your AI app can now design boards in KiCad: schematics, real orderable parts (LCSC/JLCPCB by default), layout, routing and fabrication files. KiCad checks every change.

Restart your AI app

  • Claude Desktop: right-click the tray icon, choose Quit, then reopen it. Copper appears under the tools menu.
  • Claude Code, Codex, Gemini CLI: start a new session. /mcp lists copper.
  • Cursor, VS Code, Windsurf, Zed: open the MCP settings and check that copper is enabled.

Installed an AI app after Copper? Connect it with copper install --client claude-desktop (or claude-code, codex, cursor, vscode, windsurf, zed, gemini, copilot-cli).

Ask for a board

Use Copper to design a USB-C powered ESP32-C3 board with a status LED and a
BOOT button. Use JLCPCB Basic parts, 2 layers, 30×40 mm. Show me the
schematic, then lay out and route the PCB and give me the fab files.

Or start from an existing project:

Open ~/Documents/KiCad/my-board with Copper, run a design review and
fix anything that would stop me ordering it.

Routing uses the Freerouting autorouter. If you unticked it in Setup, run copper freerouting --install once (about 120 MB); copper doctor tells you whether it is there.

What Copper does, in order

parts_searchFinds in-stock parts from your parts providers (default: LCSC, Basic parts first, no JLC setup fee).
sch_applyPlaces parts and connects pins to nets by name, in big batches.
verifyRuns KiCad's own ERC and DRC after every change. Each finding comes with a fix.
renderImages of the schematic, the board and a 3D view.
pcb_*Sync, outline, placement, routing and ground pours.
fab_exportGerbers, drill, BOM and placement file for your fab profile (default: JLCPCB; also PCBWay, OSH Park, generic or your own).

Something not working?

Open Start, then Copper for KiCad, then Copper setup (it re-checks everything and makes a test call), or run copper doctor in a terminal. Every problem it lists comes with the command that fixes it. copper install --client all re-registers Copper with every AI app it finds, and copper uninstall removes it again. Each config file Copper touched has a *.copper-backup copy.

Privacy

Copper runs on your computer, and your designs stay there. It goes online only to search and download parts (LCSC, JLCPCB, EasyEDA), to check for a newer KiCad during setup and copper doctor, to download Freerouting and a Java runtime when you ask for autorouting, and to sign in to GitHub if you link it.
